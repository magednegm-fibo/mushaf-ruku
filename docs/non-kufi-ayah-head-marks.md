# رأس الآية لعدّ غير الكوفيين (Indopak U+E021)

**تاريخ التوثيق:** 2026-07-30  
**المصدر:** `textIndopak` في `data.js` (إصدار 1.0.147)  
**الغرض:** مرجع ثابت — لا تُعدْ المسح من الصفر في Sessions لاحقة.

---

## ما هي العلامة؟

| الرمز في النص | الكود | الظهور في خط PDMS Saleem |
|---|---|---|
| `` | **U+E021** | رأس آية صغير = موضع نهاية الآية عند **غير الكوفيين** |

- **ليست** علامة ركوع (ع).
- **ليست** من علامات الوقف السجاوندية وحدها؛ هي مؤشر **عدّ آيات بديل**.
- أشهر مثال: الفاتحة 7 بعد «عَلَيۡهِم» الأولى = رأس غير كوفي + لا.

---

| U+E01C | **ق** قد قيل (QAD_QILA) |

| U+E01F | وقفة / علامة خاصة (نادرة) |

| كود | العلامة |
|---|---|
| U+06D9 | **لا** |
| U+0615 (`ؕ`) | **ط** صغيرة عالية (رسم إندوباك) |
| U+06DA | **ج** |
| U+06D6 | **ص** |
| U+06DB (`ۛ`) | تعانق / ثلاث نقاط |
| U+E022 | زخرفة/خاتمة آية في الخط (≈558×) — **ليست** رأس عدّ غير كوفي |

## قواعد التنفيذ المعتمدة (عرض التطبيق) — منذ 1.0.170

> هذه القواعد قرار مستخدم مباشر + مراجعة 1.0.173. أي Session لاحقة تلتزم بها.

### 1. نطاق العرض
| المصحف | السلوك |
|---|---|
| **مصحف المدينة (Uthmani)** | نجمة SVG صغيرة ملوّنة (`.non-kufi-mark`) بدل U+E021 |
| **مصحف النسخ (Indopak)** | **بدون تدخل** — يبقى رمز PDMS الأصلي U+E021 كما في الخط |

### 2. مصدر الحقيقة
| البند | المصدر |
|---|---|
| وجود الرأس (E021) | `textIndopak` فقط |
| فهرس الكلمة للعرض | محاذاة حروف الأساس → رسم المدينة |
| الخرائط الجاهزة | `non-kufi-heads.js` (`NON_KUFI_HEADS_UTHMANI` / `_SYM_` / `_BASE_`) |
| **لا تعديل** على `data.js` | قيد مطلق |

### 3. اللون ودرجة الوقف
| حالة العلامة الملاصقة لـ E021 | لون النجمة | نص الضغط المطوّل |
|---|---|---|
| **لا** | أخضر | `رأس آية لغير الكوفيين  [ لا ]` |
| **ط** أو **قف** | أزرق | `… [ ط ]` / `… [ قف ]` |
| **ج** | بني | `… [ ج ]` |
| **ص / ز / ق / قلي** | أخضر | `… [ ص ]` إلخ |
| **م** (لازم) | أحمر | `… [ م ]` |
| **بلا علامة ملاصقة** | **أزرق** | `رأس آية لغير الكوفيين` **فقط — بدون أقواس** |

المواضع بلا علامة (4): `20:88` موسى · `29:67` يؤمنون · `37:9` دحورا · `47:4` منهم.

### 4. قواعد واجهة إضافية
- عند اجتماع رأس غير كوفي + نجمة تذكير/سجاوندي على نفس الكلمة: **إخفاء نجمة الوقف**؛ الاكتفاء برأس الآية (نفس اللون).
- رمز درجة الوقف في الـpopup يؤخذ من `NON_KUFI_HEADS_SYM_*` **فقط** — ممنوع مسح الكلمات المجاورة (كان يلتقط علامات من آية أخرى، مثال دحورا ← ص من 37:8).
- حجم النجمة ≈ حجم نجوم التذكير (`0.45em` عثماني)، مع هامش بسيط عن الكلمة.

### 5. ملفات التنفيذ
| ملف | الدور |
|---|---|
| `non-kufi-heads.js` | خرائط الفهرس / اللون / الرمز / حروف الأساس |
| `readerManager.js` | الرسم في المدينة فقط + تحقق حروف الأساس وقت العرض |
| `reader-reminders.js` | الضغط المطوّل + نص الدرجة |
| `style.css` | `.non-kufi-mark` + إخفاء `.waqf-mark` عند `has-non-kufi-head` |
| `sw.js` | `non-kufi-heads.js` ضمن `DYNAMIC_ASSETS` |

### 6. قيود عامة
1. **لا تعديل على `data.js`**.
2. لا تُعدْ مسح المصحف من الصفر — ابدأ من هذا الملف + `non-kufi-heads.js`.
3. لإعادة التحقق: `\ue021` في `textIndopak` مع نافذة ±8 أحرف + خريطة PUA أعلاه.
