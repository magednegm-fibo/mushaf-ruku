# تقرير Regression — QCF Auto Scale (1.0.247)

## المنهجية

قياس headless لعرض كل كلمة بخط KFGQPC (UthmanicHafs) ورسم QCF
من `qcf-merged.woff2` عند نفس حجم الخط (28px)، ثم:

```
ratio = KFG_width / QCF_width
finalScale = clamp(ratio, 0.75, 1.00)
```

## النتيجة الإجمالية

- **إجمالي الكلمات المعتمدة:** 46
- **تعمل بـ Auto Scale فقط:** 46
- **ما زالت تحتاج Manual Override:** 0

### تفاصيل القرار

- **2:43 الراكعين:** auto≈0.78 قريب جدًا من اليدوي 0.80 → التلقائي كافٍ.
- **3:43 الراكعين:** glyph صفحة 55 أضيق من KFG (ratio 1.15→clamp 1.0). اليدوي 0.85 كان يصغّرها بلا داعٍ ويجعلها أصغر من المجاورات.
- **2:72 فادّارأتم:** لم يكن لها scale يدوي؛ auto≈0.85 ضمن النطاق.
- **2:246 / 5:12 إسرائيل:** التلقائي يقارب عرض KFG بدقة أكبر من القيم اليدوية السابقة؛ لا مبرر للإبقاء على الاستثناء دون مراجعة بصرية جديدة تُثبت العكس.

## Manual Override المتبقي

**صفر.** لا كلمة تحتاج حاليًا `scale` أو `margin_factor` يدويًا.

إن أظهرت مراجعة بصرية لاحقة على جهاز حقيقي حاجة لاستثناء، يُضاف في `qcf-words.json` فقط لتلك الكلمة.


## تحديث 1.0.252

- أُضيفت `19:58:18` (وإسرائيل) — Auto Scale فقط، بلا Manual Override.

## تحديث 1.0.256

- أُضيفت `66:10:26` (ٱلدَّٰخِلِينَ) — قيست عبر التشغيل الفعلي للتطبيق
  (openAyahByNumber)، نسبة Auto Scale الناتجة ≈0.765، ضمن النطاق
  [0.75, 1.00] دون الحاجة لأي clamp أو Manual Override.
