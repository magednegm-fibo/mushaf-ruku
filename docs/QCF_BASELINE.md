# خط الأساس — نظام QCF Override

**الإصدار المرجعي:** 1.0.248

اعتُمدت المعمارية الحالية كما هي. لا يُعاد تصميم البنية الأساسية ولا
يُبسَّط الكود لأسباب أداء نظرية إلا إذا ظهر سبب حقيقي يستدعي ذلك.

## ما يشمله خط الأساس

- خط مدمج واحد: `fonts/qcf-merged.woff2`
- جدول المواضع: يُولَّد من `tools/qcf-words.json` عبر `tools/build_qcf_font.py`
- التشغيل: `qcf-override.js` + `qcf-override.css`
- الحجم: Auto Scale → Auto Margin → Manual Override عند الحاجة فقط
- الألوان: كل مداخل CPAL (0–7) تُفرَض أسودًا عبر `font-palette`

## مسار العمل من الآن

1. مراجعة المصحف صفحة صفحة.
2. إضافة الكلمات التي تحتاج QCF Override فقط (عبر `qcf-words.json` ثم البناء).
3. تشغيل تحقق البناء (مدمج في `build_qcf_font.py`) بعد كل إضافة.
4. عدم أي تعديل معماري إلا لسبب حقيقي موثَّق.

التفاصيل التشغيلية: `tools/README.md`.
