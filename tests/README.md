# tests/

اختبارات انحدار (Regression Tests) لمشروع مصحف الركوع. كل ملف Node.js
مستقل، بلا خطوة بناء، يُشغَّل مباشرة:

```
node tests/<اسم الملف>.js
node tests/<اسم الملف>.js --dir /path/to/unzipped-release
```

بدون `--dir`، يعمل الاختبار على مجلد المشروع الحالي (المجلد الأب). مع
`--dir`، يعمل على أي نسخة مفكوكة أخرى — يُستخدم هذا دائمًا للتحقق من
الحزمة (ZIP) المُسلَّمة فعليًا، لا فقط من ملفات العمل.

## سجل التحديثات

### 2026-08-01 — تحديث Frozen Snapshots في sajawandi-freeze-regression.js

`sajawandi-freeze-regression.js` يحتوي قوائم مفاتيح مجمَّدة يدويًا
(`FROZEN.adds`) لكل نوع وقف، ويقارنها بمحتوى
`DEFAULT_MARK_MANUAL_ADDITIONS` الفعلي في `readerManager.js`. أي إضافة
جديدة — حتى لو صحيحة ومقصودة — تُسجَّل كفشل حتى تُحدَّث اللقطة يدويًا.
هذا مقصود: الفشل تنبيه لمراجعة التغيير، لا خطأ في حد ذاته.

حُدِّثت اللقطات المجمَّدة لثلاثة أنواع لتشمل مفاتيح دُفعتي 1.0.191
(الإضافات عالية الثقة من WAQF_REVIEW) و1.0.192 (دفعة أداة المراجعة
التفاعلية):

```
TA_MUTLAQ: +11 مفتاحًا
JEEM:      +30 مفتاحًا
ZAY_JAWAZ: +2 مفتاحًا
```

القائمة الكاملة لكل دفعة موثَّقة في `FINAL_WAQF_REVIEW_STATUS.md` و
`WAQF_REVIEW_BATCH1_REPORT.md` في جذر المشروع.

### 2026-08-01 — تصحيح توقُّع في ta-mutlaq-extraction-gap-regression.js

الموضعان:

```
2:102:66
59:9:24
```

يحملان رمز ط (TA_MUTLAQ) خامًا في `textIndopak`، لذا يدخلان بحق ضمن
دفعة استخراج ط التي يفحصها هذا الاختبار. لكن نفس الكلمة في كلا الموضعين
تحمل أيضًا رمز قف (QIF). السياسة المعتمدة في المشروع لحل هذا التعارض
(موثَّقة في تعليق `DEFAULT_QIF_WORDS` بـ`readerManager.js`: "ط+قف على
نفس توكن النسخ → قف") تجعل قف يفوز على ط دائمًا عند التعارض.

نتيجة ذلك: هذان الموضعان يُرسَمان فعليًا بصنف `has-default-qif`، لا
`has-default-waqf`. كان الاختبار يتوقع `has-default-waqf` لهما (توقُّع
قديم سابق لتفعيل سياسة حل التعارض)، فيفشل رغم أن اللون والسلوك المعروض
للقارئ صحيحان تمامًا.

عُدِّل الاختبار ليتوقع `has-default-qif` تحديدًا لهذين الموضعين (عبر
`QIF_WINS_OVER_TA_MUTLAQ` في الملف نفسه)، مع الإبقاء على توقُّع
`has-default-waqf` لباقي الـ78 كلمة كما هو. هذا ليس استثناءً دائمًا مُسكَتًا
عنه — بل تصحيح توقُّع ليطابق السلوك الصحيح والنهائي.

النتيجة بعد كِلا التعديلين: **جميع ملفات tests/*.js تنجح بالكامل (0
Failed)**، بلا أي اختبار مُستبعد أو مُهمَل.
